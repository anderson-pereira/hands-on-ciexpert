                Hardware Implementation & QoR (SAED 32nm @ 2.0 GHz)
                T = 500 ps
              

              
    
                
  • Architecture Chosen (minisoc_aes_sbox): Pure combinational 256×8-bit lookup (case(i_byte)). Synthesizes into a balanced 2-to-3-level AOI/MUX tree (~280
                  gates) with ~160 ps delay.
    • 
                
  • Timing Margin: 160 ps logic delay leaves ~340 ps for wire routing and setup time at
                  2.0 GHz, easily closing STA on SAED 32nm.
    • 
                
  • Why not Composite Fields (Canright)? Inverting algebraically in GF(((2^2)^2)^2)
                  reduces area by ~50%, but propagation delay jumps to ~750 ps — violating the 500 ps clock cycle
                  without pipeline registers.
    • 
                
  • Cryptographic Robustness: Non-linearity = 112, Maximum Differential Probability =
                  4/256 = 2⁻⁶, algebraic degree = 7. Zero fixed points (S(x) != x for all x).
                
    •

// Fundamental GF(2^8) x2 primitive: 3 XOR2 gates, 1 gate-level logic depth!
function automatic logic [7:0] xtime(input logic [7:0] b);
  return {b[6:0], 1'b0} ^ (b[7] ? 8'h1b : 8'h00);
endfunction

            MiniSoC AES Hardware Primitives Summary (SAED 32nm @ 2.0 GHz)
            T_clk = 500 ps
          

          

            

              
                

                  Primitive
                  Hardware Structure
                  Gate / Delay Profile
                  Used In
                

              
              
                

                  SubBytes / InvSubBytes
                  16 parallel 256×8-bit constant LUTs (case)
                  Synthesizes into compact 2-input MUX/AOI cones; avoids deep GF(2^8) inverter chain to close 500 ps
                    STA.
                  Cipher, InvCipher (ECB/CBC/PCBC), Forward S-Box in KeyGen
                

                

                  ShiftRows / InvShiftRows
                  Pure wire permutation:
c' = (c ± r) mod 4		
                  0 gates, 0 ps logic delay (routing only). Commutes with SubBytes / InvSubBytes!
                  
                  Cipher (left shift), InvCipher (right shift)
                

                

                  MixColumns
                  4 parallel column slices using xtime + 4-way XOR
                  ~3–4 XOR levels per byte (108 XOR2 gates across 128 bits). Omitted in Round 10.
                  Cipher Rounds 1..9 (and all stream modes CTR/CFB/OFB)
                

                

                  InvMixColumns
                  Chained x2, x4, x8 XOR trees ({0e,0b,0d,09})
                  
                  ~5–6 XOR levels per byte; deeper than forward MixColumns — critical STA path in shared datapaths!
                  
                  InvCipher Rounds 1..9 (ECB, CBC, PCBC Decrypt only)
                

                

                  AddRoundKey
                  128 parallel XOR2 gates (state ^ rk)
                  1 XOR2 gate delay; self-inverse ((x ^ k) ^ k == x).
                  Every round (R0..R10) in both Cipher and InvCipher
                

                

                  KeyExpansion
                  RotWord + 4× Forward S-Box + Rcon + 3-level
                    32b XOR cascade
                  S-Box + 4 XOR levels forward; S-Box + 2 XOR levels in reverse (RK10 →
                      RK0).
                  Key schedule (RK0..RK10)
                

              
            

          


          
    
            
  • Synchronous Reset First (QoR Rule): All sequential datapath, FSM, key-schedule, and
              IV/chaining registers use always_ff @(posedge clk) if (!rst_n) to maximize
              Synopsys DC QoR, enable clean ICG clock gating, and eliminate async recovery/removal arcs at 2.0 GHz.
    • 
            
  • Stream-Mode Hardware Insight: Modes CTR, CFB, and OFB NEVER invoke InvCipher — even when CTRL.OP == DECRYPT, the AES core
              runs in forward Cipher direction!
